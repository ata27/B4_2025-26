# physical_data

Physical atmosphere data used alongside the kinetic_data tables.

- `us_standard_atmosphere_1976.csv` — precomputed T (K), P (Pa), and air
  number density [M] (molecule cm^-3) from 0-86 km at 0.5 km resolution,
  generated by the `standard_atmosphere()` function in
  `../kinetic_data/kinetics.py`. Used to convert termolecular rate
  coefficients k([M],T) (Table S2) into profiles vs. altitude.
